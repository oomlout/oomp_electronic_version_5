# IC Microcontroller Wifi Bluetooth QFN_33_5_MM_X_5_MM

IC Microcontroller Wifi Bluetooth QFN_33_5_MM_X_5_MM is an OOMP electronic ic definition. It uses the qfn 33 5 mm x 5 mm package or form factor. Its nominal drawing size is 5.0 &#x00D7; 5.0 mm. The definition includes 33 documented pins.
