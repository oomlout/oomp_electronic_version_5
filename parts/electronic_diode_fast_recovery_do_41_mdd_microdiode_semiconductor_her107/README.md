# Diode HER107 DO-41

`electronic_diode_fast_recovery_do_41_mdd_microdiode_semiconductor_her107`

Diode HER107 DO-41 is an OOMP electronic diode definition. It uses the do 41 package or form factor. Its nominal drawing size is 10.0 &#x00D7; 5.0 mm.


![Diode HER107 DO-41 studio render](data/display_render/render.png)

KiCad DO-41 model has bent leads at 10.16 mm pitch; the manufacturer drawing shows straight leads at least 25.4 mm long. Display illustration only; not manufacturing CAD or a PCB footprint. The source 10 x 5 mm dimensions are placeholders and no KiCad footprint is selected. HER107 is an illustrative partial identifier from the MDD family marking; the MDD logo is omitted. Typeface, placement and stripe width are illustrative.
