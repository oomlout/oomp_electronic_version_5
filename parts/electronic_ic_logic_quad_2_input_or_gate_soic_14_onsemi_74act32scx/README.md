# IC 74ACT32SCX SOIC 14

`electronic_ic_logic_quad_2_input_or_gate_soic_14_onsemi_74act32scx`

IC 74ACT32SCX SOIC 14 is an OOMP electronic ic definition. It uses the soic 14 package or form factor. Its nominal drawing size is 8.7 &#x00D7; 3.9 mm. The definition includes 14 documented pins.


![IC 74ACT32SCX SOIC 14 studio render](data/display_render/render.png)

Illustrative KiCad SOIC-14 model with 1.75 mm overall height. Catalogue lists 1.75 mm height. onsemi case 751EF drawing specifies 1.75 mm maximum; exact case is not asserted where the ordering table only lists SOIC-14. Not a verified mechanical model. onsemi lists ACT32 as the package marking. Typeface, orientation, placement and variable lot/date details are illustrative. Marking composited in linear light from shared path-traced material passes; indirect reflections are approximate.
