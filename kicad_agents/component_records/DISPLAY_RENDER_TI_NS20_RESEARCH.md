# TI 20-pin NS versus DB package research

Reviewed 2026-11-19. Seven local `...NSR` logic records currently specify `Package_SO:SSOP-20_5.3x7.2mm_P0.65mm` and 7.2 x 5.3 x 1.98 mm. Do not blindly render from that footprint: [TI SN74HC374 ordering table](https://www.ti.com/lit/ds/symlink/sn74hc374.pdf) explicitly identifies SN74HC374NSR as 20-pin SOP NS and marks it `HC374`, while identifying the DB variant as SSOP. The [TI product overview](https://www.ti.com/product/SN74HC374) lists NS 12.6 x 7.8 mm and DB 7.2 x 7.8 mm package summaries. The same TI datasheet body-size table instead lists NS 15.0 x 5.3 mm and DB 7.2 x 5.3 mm, while its packing table lists NS cavity 13.0 x 8.4 mm; these values are not necessarily the same measurement and are not reconciled. Find the applicable NS package drawing and compare body, lead pitch, height and lead span individually before picking a generic display model. Preserve all source records; disclose any mismatch and limitations. The KiCad SOIC-20W model may be a possible visual approximation but has not yet been mechanically compared.

The eighth footprint-group record `electronic_ic_logic_octal_bus_buffer_tri_state_ssop_20_208mil_texas_instruments_sn74hct244dbr` is a DB orderable, not an NS record; evaluate separately against its own drawing, source identity, marking and KiCad model. A source-footprint group is a research lead, not evidence that variants share a package.
Manufacturer drawing resolution: TI's exact SN74HC374NSR product page links [NS R-PDSO-G14/16/20/24 drawing MSOP002A](https://www.ti.com/lit/pdf/MSOP002A). Visually reviewed its first page in Chrome on 2026-11-19: for 20 pins, body length A is 12.30–12.90 mm, body width 5.00–5.60 mm, lead span 7.40–8.20 mm, pitch 1.27 mm, seated height 2.00 mm maximum. The local 7.2 mm / 0.65 mm SSOP footprint is incompatible with this drawing. The TI datasheet summary of 15.00 x 5.30 mm remains inconsistent with that drawing; the linked drawing and NS package identification are stronger evidence. A KiCad SOIC-20W model could be scaled in X to 75% and height from 2.75 to 2.00 mm for an explicitly approximate display: lead span becomes 7.725 mm and body width about 5.625 mm (0.025 mm above max), with length 12.8 mm and 1.27 mm pitch retained. This is not a PCB or verified mechanical model; no source data has been changed.
