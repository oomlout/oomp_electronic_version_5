# CCO CF1/6W 2.4 kΩ display evidence

The selected [CF1/6W-2.4KΩ±5% T / C119879](https://jlcpcb.com/partdetail/CCO_Chian_Chia_Elec-CF1_6W_2_4K_5_T/C119879) is a 2.4 kΩ, 5%, 167 mW carbon-film resistor with a 3.2 × 1.8 mm body. The full part number was restored from the supplier listing; the previous source contained only `T`.

The [CCO carbon-film specification](https://datasheet.lcsc.com/lcsc/2410121228_CCO-Chian-Chia-Elec-CF1-4W-2KR-5--T_C120062.pdf) documents four-band 5% coding. The resulting code is red, yellow, red, gold. Beige coating and stripe spacing are illustrative. The 3.6 × 1.6 mm KiCad DIN0204 body approximates the supplier-listed dimensions, with leads formed at 7.62 mm pitch.

The existing quarter-watt ID, larger body dimensions and DIN0207 footprint require separate catalogue review. The manufacturer specification was read online; no local PDF is claimed.
