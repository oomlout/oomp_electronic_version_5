# Yageo MFR-25 zero-ohm jumper display evidence

[DigiKey identifies MFR-25-T-52-0R](https://www.digikey.com/en/products/detail/yageo/MFR-25-T-52-0R/9145052)
as a Yageo 0 Ω, quarter-watt axial jumper. The selected record uses LCSC
C173063. The generic KiCad bent-lead model has an illustrative beige body.

A centered black band is a common zero-ohm visual convention, also documented
for Vishay's [SMM/OMM0207 cylindrical jumpers](https://www.vishay.com/docs/20005/smm0207.pdf).
That is a different product family and does not verify the selected Yageo
part's actual body marking, band position or coating. The image explicitly
identifies its black band and beige colour as illustrative. A 0 Ω jumper has
no resistance-tolerance band, so it does not receive a gold band.
Manufacturer pages were reviewed online; no local PDF is claimed.
