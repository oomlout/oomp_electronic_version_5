# Fenghua 0603 low-value C0G display evidence

Reviewed 2026-11-18. Fenghua general series specification FH-2016-001,
reproduced at https://pdf.elecfans.com/p/5746704.html, gives nominal
0603 dimensions 1.60 × 0.80 × 0.80 mm and decodes tolerance code C as
±0.25 pF. These are family-level dimensions; exact individual thicknesses
have not been independently verified. Source records omit tolerance.
