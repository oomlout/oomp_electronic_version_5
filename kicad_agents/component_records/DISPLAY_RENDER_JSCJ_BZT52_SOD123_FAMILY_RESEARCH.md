# JSCJ BZT52 SOD-123 family markings

The existing BZT52C10 local JSCJ family datasheet, SHA-256 `fd5a910fc58737806f1596a6318cecd1e1264061e3ca7c6c7f13e69667e36ab5`, was inspected visually: page 2 provides the type-code table and page 4 the SOD-123 outline. Page 1 shows a cathode stripe and an optional green-moulding dot. The dot is omitted because these records do not establish it. The KiCad model's 1.26 mm height exceeds the drawing's 1.25 mm maximum by 0.01 mm. Typeface, placement and finish remain illustrative.

The family PDF is stored with BZT52C10, not duplicated into these part folders. It identifies the family members below but does not independently establish availability of each exact orderable or production marking variation. For the catalogue's `BZT52C8V2 WD`, WD matches the family type code; whether it is an orderable suffix is unverified.
