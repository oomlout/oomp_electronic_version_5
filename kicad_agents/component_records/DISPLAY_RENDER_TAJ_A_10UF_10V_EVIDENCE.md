# TAJ A-case 10 µF 10 V illustrative display

Reviewed 2026-11-18. KYOCERA AVX TAJ manufacturer datasheet
https://datasheets.kyocera-avx.com/TAJ.pdf pages 1–2 gives A-case nominal
3.20 × 1.60 × 1.60 mm, the positive-anode polarity stripe and a marking
scheme with capacitance code and rated-voltage letter. It gives code 106
for 10 µF and A for 10 V, while permitting shipment at a higher voltage
rating. The exact selected TAJA106K010RNJ / C7177 is identified as
10 µF 10 V at https://www.lcsc.com/product-detail/C7177.html.

The illustration uses KiCad's Kemet A-case model scaled from 1.80 to 1.60 mm
height, with a red polarity stripe and dark `106 A` text. Actual ink, body
colour, logo, lot code and any higher-rated substitute marking can differ; no
production code or maker logo is invented. The model is for display only.
The original manufacturer drawing was read online; no PDF downloaded.
