# Fenghua RC-MT08W resistor-array display evidence

Reviewed online: Fenghua's manufacturer-authored thick-film network resistor
catalogue, version 7.0, at
https://szsdmdz.com/wp-content/uploads/2024/12/%E9%A3%8E%E5%8D%8E%E9%AB%98%E7%A7%91-%E5%8E%9A%E8%86%9C%E7%89%87%E5%BC%8F%E7%BD%91%E7%BB%9C%E7%94%B5%E9%98%BB%E5%99%A8-7.0.pdf

The ordering table describes RC-MT08W as an eight-terminal convex network of
four 0402 resistors and gives the three-character resistance code and decimal
convention. The dimensions table gives 2.00 × 1.00 × 0.45 mm, height ±0.10 mm.
The KiCad 4×0402 array measures 2.00 × 1.00 × 0.35 mm: its height is at the
manufacturer tolerance limit, so this is nominal illustrative geometry. The
manufacturer's top view depicts a value code on RC-MT08/RC-ML08; unlike an
individual 0402 resistor this array must not be assumed unmarked.

Inspect the exact manufacturer, part number, resistance, number of resistors,
terminal count and footprint for every component. Typeface, ink, placement and
materials are illustrative. This record is an online review; no local PDF has
been captured.
