# Toshiba TC7SU04F,LF SOT-25 evidence

Toshiba [product page](https://toshiba.semicon-storage.com/eu/semiconductor/product/general-purpose-logic-ics/detail.TC7SU04F.html) lists TC7SU04F,LF as an orderable example and SOT-25 (SMV), with overall 2.9 × 2.8 × 1.1 mm package dimensions. Source record has 2.9 × 1.6 mm and SOT-23-5 footprint without height. KiCad generic SOT-23-5 is scaled vertically from 1.55 to 1.1 mm for display, not a verified footprint.

The [Toshiba datasheet](https://toshiba.semicon-storage.com/info/TC7SU04F_datasheet_en_20170802.pdf?did=20190&prodName=TC7SU04F) depicts E6 in a marking diagram. This is an illustrative example, not a verified full production marking; typography, orientation and placement are illustrative.
