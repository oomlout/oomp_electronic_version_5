# Initial LED and connector display inventory

Read-only source inventory on 2026-11-21 found 555 connector records; 237 have no selected machine-solder footprint. The rest include many KiCad pin-header and 4Ucon terminal-block footprints. This is a footprint inventory, not a claim that every footprint or 3D model matches its exact part. Several records represent the same generic footprint with different pin lengths or colours; validate the particular variant and source before reusing geometry. Prior crimp-housing and contact work may already contain display assets outside the new display-render manifest pipeline; inspect those assets before regenerating anything.

The generic `electronic_led_0201_blue` record specifies emitted colour, 0.6 x 0.3 mm nominal dimensions and KiCad `LED_SMD:LED_0201_0603Metric`, but has no identified manufacturer or marking. KiCad `LED_0201_0603Metric.step`, SHA-256 `bcd380f55739b52e1c5111fcd4660667bb8fb66d0afc85738f969da7fa06d67b`, measures approximately 0.65 x 0.35 x 0.20 mm overall and has ceramic, terminal and green regions. Geometry inspection places the green region at z=0.0085–0.017 mm, underneath the body, not a visible illuminated lens. Do not recolour that underside region to imply the LED's emitted colour or invent a package code. An unlit generic package illustration may be possible with the correct KiCad source credit, while emitted colour, unspecified lens appearance, nominal-vs-model bounds and absence of an identified exact part must remain explicit.

The selected 0201 example is one taxonomy record, not proof that all LED family variants have identical physical packages. Review each package and colour/lens description separately; do not infer whether a lens is tinted from emission colour alone. No LED image or catalogue entry was generated by this inventory.
