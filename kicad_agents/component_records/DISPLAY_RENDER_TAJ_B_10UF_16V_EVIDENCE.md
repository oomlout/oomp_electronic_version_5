# TAJ B-case 10 µF 16 V illustrative display

Reviewed 2026-11-18. KYOCERA AVX TAJ manufacturer datasheet
https://datasheets.kyocera-avx.com/TAJ.pdf pages 1–2 gives B-case nominal
3.50 × 2.80 × 1.90 mm, the positive-anode polarity stripe and a marking
scheme with capacitance code and rated-voltage letter. It gives code 106
for 10 µF and C for 16 V, while permitting higher voltage substitutions.
The selected TAJB106K016RNJ is identified as 10 µF / 16 V / B-case in
https://www.tme.com/us/en-us/details/tajb106k016r/smd-tantalum-capacitors/kyocera-avx/tajb106k016rnj/

The illustration uses KiCad's Kemet B-case model scaled from 2.10 to 1.90 mm
height, with a red polarity stripe and dark `106 C` text. Actual ink, body
colour, logo, lot code and any higher-rated substitute marking can differ; no
production code or maker logo is invented. The model is for display only.
The manufacturer drawing was read online; no PDF downloaded.
