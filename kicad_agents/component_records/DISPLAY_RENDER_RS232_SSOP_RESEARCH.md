# RS-232 SSOP display research

MaxLinear's [SP3223E datasheet](https://www.maxlinear.com/ds/sp3223e_sp3223eb_sp3223eu.pdf) identifies `SP3223EEA-L/TR` as a 20-pin SSOP, and its [SP3243E datasheet](https://www.maxlinear.com/ds/sp3243e.pdf) identifies `SP3243EEA-L/TR` as a 28-pin SSOP. The manufacturer's [SP3223E](https://www.maxlinear.com/product/interface/serial-transceivers/rs-232/sp3223e) and [SP3243E](https://www.maxlinear.com/product/interface/serial-transceivers/rs-232/sp3243e) product pages corroborate those package counts. Analog Devices' [ADM213E page](https://www.analog.com/en/products/adm213e.html) lists `ADM213EARSZ` as 28-lead SSOP, but the source record's reel suffix and exact manufacturer marking still require confirmation.

These references identify package families, not complete mechanical dimensions or physical top markings. Before staging a part, verify its exact orderable, source metadata, manufacturer's package drawing, width, length, pitch and height against a specific KiCad model. Use illustrative family text only if the actual marking remains unverified, and disclose any conflict with the catalogue's dimensions. No candidate has been staged from this preliminary research.
