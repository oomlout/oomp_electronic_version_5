# Philips N74F377AD SO20 representative example evidence

A Philips-authored [historical datasheet](https://www.sm0vpo.com/_pdf/74_TTL/74F377A.PDF) lists `N74F377AD` in 20-pin SOL SOT163-1. The catalogue says `74F377AD` without the N prefix; exact equivalence is unconfirmed, so the render represents the N-prefixed example and does not verify the catalogue MPN. Its generic [SOT163-1 package](https://assets.nexperia.com/documents/outline-drawing/SOT163-1.pdf) uses a 7.5 mm wide body and 2.65 mm maximum height. Exact production marking has not been established; `74F377A` is an illustrative family identifier. Typeface, placement, orientation, logos and variable production details are illustrative.

Source dimensions are 12.8 × 7.5 × 2.65 mm. The generic KiCad SOIC20W model is scaled vertically from 2.75 to 2.65 mm as a display approximation, not a verified mechanical model or PCB footprint.
