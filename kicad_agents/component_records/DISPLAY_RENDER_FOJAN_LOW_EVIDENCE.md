# FOJAN FRC low-value resistor display evidence

Reviewed online: FOJAN FRC thick-film resistor product specification
FJ-JS-3001 V1.0, 3 July 2023, pages 1–3:
https://datasheet.lcsc.com/datasheet/pdf/a989bb6b3ce1fee6bebaf3c423fa14e9.pdf?productCode=C22375100

For 1% FRC devices the MPN uses four characters for the value, with R as
the decimal point. The 0201 and 0402 packages have no body marking. For 0805
and 1206, the marking section shows four characters and gives 6R81 as an
example below 100 ohms. For 0603 1% E96 values, use its three-character
multiplier table. For 0603 1% E24 values that are not E96, use the 5% code
with a line beneath the middle character; for 10–99 ohms the two digits are
followed by zero (the table illustrates 560 for 56 ohms). Verify each exact
primary manufacturer, MPN, value, tolerance and selected footprint.

The installed KiCad package is generic display geometry; colour, typeface,
mark position and materials are illustrative. This manufacturer document was
read online and is not claimed to be captured as a local PDF.
