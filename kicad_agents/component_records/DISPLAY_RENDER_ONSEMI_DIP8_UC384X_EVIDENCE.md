# onsemi UC384xB DIP-8 batch evidence

Reviewed 2026-11-19. Onsemi's [UC3842B/UC3843B datasheet](https://www.onsemi.com/download/data-sheet/pdf/uc3842b-d.pdf) lists UC3842BNG and UC3843BNG as PDIP-8 and depicts the first marking line `UC384xBN`, where x is 2 or 3. Its [UC3844B/UC3845B datasheet](https://www.onsemi.com/download/data-sheet/pdf/uc3844b-d.pdf) lists UC384xBNG PDIP-8 with x explicitly defined as 4 or 5 and depicts the same first-line pattern. Date/lot/manufacturer lines are omitted; typeface, orientation and placement illustrative.

The onsemi case 626 drawing specifies 2.54 mm pitch and 9.02–10.16 mm body length. Source records list 10 x 5 mm without height, width reference or footprint. The generic KiCad DIP-8 W7.62 model has 7.874 x 9.27 x 6.98 mm total bounds including projecting pins. It is a display illustration, not a verified mechanical model or PCB footprint. The source width reference is not established; do not assert exact width equivalence.
