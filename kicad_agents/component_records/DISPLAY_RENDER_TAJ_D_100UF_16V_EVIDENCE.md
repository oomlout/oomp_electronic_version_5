# TAJ D-case 100 µF 16 V illustrative display

Reviewed 2026-11-18. KYOCERA AVX TAJ manufacturer datasheet
https://datasheets.kyocera-avx.com/TAJ.pdf pages 1–2 gives D-case nominal
7.30 × 4.30 × 2.90 mm, the positive-anode stripe and marking scheme.
Code 107 denotes 100 µF and C denotes 16 V; higher voltage substitutions
are allowed. Selected TAJD107K016RNJ / C7223 is identified as 100 µF /
16 V / D-case at https://www.lcsc.com/product-detail/C7223.html

The illustration uses KiCad's Kemet D-case model scaled from 3.10 to 2.90 mm
height, with a red polarity stripe and dark `107 C` text. Actual ink, body
colour, logo, lot code and any higher-rated substitute marking can differ; no
production code or maker logo is invented. The model is display only.
Manufacturer drawing was read online; no PDF downloaded.
