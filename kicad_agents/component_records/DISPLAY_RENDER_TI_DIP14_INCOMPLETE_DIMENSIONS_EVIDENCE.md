# TI DIP-14 batch with incomplete catalogue dimensions

Reviewed 2026-11-19. Individual TI datasheets and package addenda identify each exact orderable as 14-pin PDIP (N) and list the stated device marking. All local records list 10 × 5 mm, omit height and lack machine footprints. Those values disagree substantially with the manufacturer's N package nominal body 19.3 × 6.4 mm; the source dimension reference is unspecified and the conflict is explicit on every display page. The generic KiCad DIP-14 model is illustrative and is not a verified footprint or mechanical drawing. Its 6.98 mm total height includes projecting pins; typography, orientation and variable lot/date/manufacturer marks are illustrative. The independent pilot and shared-pass comparison must pass before staging.
