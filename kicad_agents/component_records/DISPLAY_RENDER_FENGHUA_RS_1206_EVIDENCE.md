# Fenghua RS-06 1206 display evidence

The Fenghua general chip resistor approval sheet R-6.1, reviewed online at
https://datasheet.lcsc.com/lcsc/Guangdong-Fenghua-Advanced-Tech-RS-06000JT_C115323.pdf,
lists RS-06 in its scope. Page 4 decodes the 1206 size, E24 resistance code,
J tolerance (±5%), and K temperature coefficient. Page 7 specifies a
three-digit value code for E24 parts and permits customer-specific markings.
Page 3 gives the nominal 3.2 × 1.6 × 0.55 mm 1206 package.

The image is a display illustration using generic KiCad package geometry;
materials, typeface and placement are illustrative. Manufacturer sheet was
inspected online: no local PDF is claimed.
