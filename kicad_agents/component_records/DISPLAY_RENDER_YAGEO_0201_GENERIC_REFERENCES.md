# Yageo visual references for unsourced generic 0201 resistors

The source records specify package and nominal resistance, but no manufacturer
or tolerance. Images illustrate the named 1% Yageo RC_L parts; this does not
assign a tolerance or supplier to the generic catalogue entry. Model geometry,
finish and lighting are illustrative. Yageo's RC_L specification states that
RC0201 packages have no marking:
https://robu-prod-media.s3.ap-south-1.amazonaws.com/uploads/2025/08/C137992.pdf
The specification was inspected online; no local PDF is claimed.
