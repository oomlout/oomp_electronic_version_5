# SGMICRO SGM358 MSOP-8 display evidence

SG Micro [datasheet](https://www.sg-micro.com/rect/assets/4904b7ef-dcb3-4c7c-8a4f-814aa8120464/SGM321_SGM358_SGM324.pdf) lists SGM358YMS/TR as MSOP-8 with marking SGM358 / YMS and five variable date/vendor characters. The catalogue ID implies that orderable but its manufacturer and MPN fields are absent; the represented SGMICRO example is inferred from the ID. Datasheet MSOP-8 drawing gives body 2.9–3.1 × 2.9–3.1 mm, lead span 4.75–5.05 mm, 0.65 mm pitch and height 0.82–1.10 mm. Catalogue lists 3 × 3 × 1.1 mm and MSOP-8 footprint; the KiCad model has 4.9 × 3.0 × 0.95 mm overall bounds and is an illustrative generic display model.

The two fixed marking lines SGM358 / YMS follow the manufacturer table. Variable date/vendor code characters are omitted; typography, placement and orientation are illustrative, so the displayed marking is incomplete.
