# TI DS90LV032ATMX/NOPB SOIC-16 display evidence

Reviewed 2026-11-19. TI's [exact orderable table](https://www.ti.com/lit/ds/symlink/ds90lv032a.pdf) lists SOIC D 16 and a part-marking entry rendered in the table as `DS90LV032A` followed by `TM`. TI's table notes that an indented continuation combines with the preceding line; this is a table wrap and does not establish the physical chip's line break. For legibility this display lays those documented characters out on two illustrative lines (`DS90LV032A` / `TM`); the placement, typeface and break are not claimed as a real package layout. Logo and traceability are omitted. [D0016A](https://www.ti.com/lit/ml/mpds432a/mpds432a.pdf) specifies 9.8–10.0 × 3.8–4.0 mm body, 1.27 mm pitch, 1.75 mm maximum height. Source lists 9.9 × 3.9 mm but omits height and machine-solder footprint. Display is not a verified PCB footprint.
