# Microchip AT-series SOIC-8 marking research

Reviewed 2026-11-19. These are research leads, not approved render recipes.
Microchip's package marking diagrams include variable assembly/date/country
and traceability fields around a shortened device code. Do not present a
device code as a complete top marking. If using a partial marking in a display,
explain the omitted fields and verify its exact placement and voltage suffix.
Check each exact catalogue MPN, package and source dimensions against its own
manufacturer ordering and drawing information before staging. No PDF was
downloaded.
