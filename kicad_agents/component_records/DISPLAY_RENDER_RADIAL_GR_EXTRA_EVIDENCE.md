# Chengx GR additional radial display candidates

Reviewed 2026-11-19. [LCSC C2033](https://www.lcsc.com/product-detail/C2033.html)
identifies GR477M010F12RR0VL4FP0 as 470 µF / 10 V, 8 × 12 mm, 3.5 mm pitch;
[LCSC C5154](https://www.lcsc.com/product-detail/C5154.html) identifies
GR477M025F14RR0VL4FP0 as 470 µF / 25 V, 8 × 14 mm, 3.5 mm pitch; and
[LCSC C2036](https://www.lcsc.com/product-detail/C2036.html) identifies
GR227M010E11RR0VH4FP0 as 220 µF / 10 V, 6.3 × 11 mm, 2.5 mm pitch.
All three are polarized.

The [Chengx part-number key](https://xonstorage.z8.web.core.windows.net/pdf/chengxing_1000uf10v_Lcs01_link.pdf)
defines sleeve code `L` as green, `H` as black, and ink code `4` as gold.
The two VL4 parts therefore use green/gold; the VH4 part uses black/gold.
The exact shades, font, text placement, negative stripe and surface finish
remain illustrative. Each size still needs an independently verified model,
pad-2 polarity and inspected preview and final image. No PDF was downloaded.
