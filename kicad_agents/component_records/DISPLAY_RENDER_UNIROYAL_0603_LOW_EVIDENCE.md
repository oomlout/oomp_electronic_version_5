# UNI-ROYAL 0603 low-value E24 display evidence

Manufacturer-authored UNI-ROYAL thick-film chip resistor specification,
7 February 2017 version 2, page 6, reviewed online:
https://mm.digikey.com/Volume0/opasdata/d220001/medias/docus/5561/Thick%20Film%20Chip%20Resistors.pdf

Section 4.0(3) gives the 5% code 2R2 for 2.2 ohms and describes R as the
decimal point below 10 ohms. Section 4.0(5) says 0603 1% E24 values outside
E96 use the same 5% code with an underline. Therefore 2.2, 4.7 and 5.1 ohms
use the underlined codes 2R2, 4R7 and 5R1, respectively. The local UNI-ROYAL
2019 family sheet at `parts_source/electronic_resistor_0402_0_ohm/datasheet.pdf`
also documents the 0603 E24 exception and part-number fields on pages 2–4.
The 2017 document was reviewed online; no local copy of it is claimed.

KiCad model geometry, body finish, typeface, ink and underline placement are
illustrative. Verify each exact manufacturer, primary MPN, value, tolerance
and footprint before applying the rule.
