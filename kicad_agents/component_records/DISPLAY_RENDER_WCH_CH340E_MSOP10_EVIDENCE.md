# WCH CH340E MSOP10 display evidence

The catalogue ID names WCH CH340E, but the source record has no manufacturer or manufacturer part number. Identity is inferred from that ID, not independently verified for an owned physical device. [WCH's CH340 datasheet](https://cdn.sparkfun.com/assets/e/3/c/3/1/DS-16278-CH340E.pdf) identifies CH340E as 10-pin MSOP with 3.0 mm body width and 0.5 mm pitch. The catalogue selects an MSOP-10 3 × 3 mm footprint and 1.1 mm height, though its package drawing's pin coordinates imply inconsistent 0.6 mm pitch.
