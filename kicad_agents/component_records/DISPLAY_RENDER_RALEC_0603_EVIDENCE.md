# RALEC RTT03 1% 0603 marking evidence

The manufacturer-authored [RALEC RTT specification IE-SP-010](https://www.bdtic.com/DataSheet/RALEC/IE-SP-010.pdf),
released 20 February 2011 and reviewed online, specifies the EIAJ-96 code for
1% RTT03 parts in section 9.1.3. Its E96 table identifies 590 as code `75`
and multiplier `X` as 0.1; the 59 Ω part is therefore marked `75X`.
The same specification describes an underlined E24 exception; low-value E24
parts require separate review of the precise mark before they are rendered.

The inspected KiCad 0603 model is generic display geometry; typeface, ink,
placement and materials are illustrative. The online PDF was not downloaded.
The existing local RALEC IE-SP-007 family sheet is a different edition.
