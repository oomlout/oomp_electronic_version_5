# Microchip SOIC-8 SPI and Microwire EEPROM partial marking review

Reviewed 2026-11-19. The manufacturer SN package drawings specify 4.9 × 3.9 mm body, 1.27 mm pitch and 1.75 mm maximum height. Local sources omit height. The KiCad SOIC-8 is illustrative.

The three-character text is only the manufacturer catalog truncation code within a multi-line top marking. Voltage suffix, logo, country, date and trace fields are intentionally omitted; typography, centered placement and scale are illustrative. The 93C46DN-SH-T exact suffix is interpreted from Microchip's ordering structure, where -T specifies tape and reel and -SH denotes SOIC/industrial grade; manufacturer example explicitly lists the -B version.
