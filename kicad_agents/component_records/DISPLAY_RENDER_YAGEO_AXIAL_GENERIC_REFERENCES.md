# Yageo visual references for unsourced generic axial resistors

These generic quarter-watt entries specify a nominal resistance and footprint,
but no selected manufacturer or tolerance. Each image illustrates a documented
Yageo part, without assigning its supplier or tolerance to the generic entry.
The traditional beige finish, shades and bent leads are illustrative.

Yageo's [CFR specification](https://s3.amazonaws.com/snapeda/datasheet/CFR-12JB-52-1M_Yageo.pdf)
describes a four-band value code with a gold 5% tolerance band. Yageo's
[MFR specification](https://robu-prod-media.s3.ap-south-1.amazonaws.com/uploads/2025/02/2499275.pdf)
describes a five-band 1% code with a brown tolerance band. Both were reviewed
online; no local manufacturer PDF is claimed.
