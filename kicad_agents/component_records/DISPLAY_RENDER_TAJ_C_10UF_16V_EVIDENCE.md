# TAJ C-case 10 µF 16 V illustrative display

Reviewed 2026-11-18. KYOCERA AVX TAJ manufacturer datasheet
https://datasheets.kyocera-avx.com/TAJ.pdf pages 1–2 gives C-case nominal
6.00 × 3.20 × 2.60 mm, the positive-anode polarity stripe and a marking
scheme with capacitance code and rated-voltage letter. Code 106 denotes
10 µF and C denotes 16 V; higher voltage substitutions are allowed.
Selected TAJC106K016RNJ / C7209 is identified as 10 µF / 16 V / C-case at
https://www.lcsc.com/product-detail/Tantalum-Capacitors_AVX_TAJC106K016RNJ_10uF-106-10-16V_C7209.html

The illustration uses KiCad's Kemet C-case model scaled from 2.80 to 2.60 mm
height, with a red polarity stripe and dark `106 C` text. Actual ink, body
colour, logo, lot code and any higher-rated substitute marking can differ; no
production code or maker logo is invented. The model is display only.
Manufacturer drawing was read online; no PDF downloaded.
