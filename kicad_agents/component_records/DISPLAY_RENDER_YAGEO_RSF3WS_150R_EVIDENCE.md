# YAGEO RSF3WS 150 Ω display evidence

The selected [RSF3WSJT-73-150R / C1392170](https://www.lcsc.com/product-detail/C1392170.html) is a 150 Ω, 5%, 3 W part. The [YAGEO RSF specification](https://yageogroup.com/content/datasheet/asset/file/YAGEO-RSF_DATASHEET) identifies RSF as metal-oxide film, specifies a 15.5 ±1 × 5 ±0.5 mm RSF3WS body and documents four-band 5% colour coding: brown, green, brown, gold. The source supplier description calls it metal film; the manufacturer identifies it as metal oxide.

The generic KiCad DIN0516 model matches the nominal body and has formed leads at 20.32 mm. The existing quarter-watt ID, smaller 6.5 × 2.5 mm dimensions and 7.62 mm footprint require separate catalogue review. Beige coating and stripe spacing are illustrative. The specification was read online; no local PDF is claimed.
