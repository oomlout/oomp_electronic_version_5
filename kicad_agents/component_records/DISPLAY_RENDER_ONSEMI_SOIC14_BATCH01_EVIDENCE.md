# onsemi SOIC-14 logic batch 01 evidence

Reviewed 2026-11-19. Each onsemi ordering table links the exact orderable SOIC-14 device to its marking. Local records use a 3.9 x 8.7 mm SOIC-14 footprint. Seven list 1.75 mm height; 74VHC08MX has no source height. The generic KiCad SOIC-14 model measures 6.0 x 8.7 x 1.75 mm overall. Onsemi's case 751EF drawing gives 1.75 mm maximum overall height, not an exact nominal measurement. The cited ordering tables for AC04 and ACT00 identify SOIC-14 without specifying a case code; use generic package illustration, not a claim of exact mechanical equivalence. Typeface, pin-one indicator, placement, orientation, logo and lot/date codes are illustrative.
