# Fenghua RS 0603 2.7 Ω 5% display evidence

Selected FH RS-03L2R7JT is a 0603 2.7 Ω 5% resistor, as recorded by
[JLCPCB C1186](https://jlcpcb.com/partdetail/1538-RS03L2R7JT/C1186).
The existing local Fenghua general thick-film chip resistor specification
`parts_source/electronic_resistor_0402_150000_ohm_5_percent/datasheet.pdf`
(SHA-256 `0ef05b6c930def860b42d0640b3b0eacb5ab469b47b3235801b55223c249958d`) documents the RS part-number system on page 1,
5% E24 three-character markings on page 11, and R as decimal point on page 12.
The 2R7 value code therefore denotes 2.7 Ω. Customer-specific markings can
differ. The generic KiCad package, materials, typeface and positioning are
illustrative.
